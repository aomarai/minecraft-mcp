# Security Policy

## Reporting a vulnerability

Do not open a public issue for an exploitable problem. Use GitHub's private vulnerability
reporting on this repository, or contact the maintainer directly.

Include affected versions, reproduction steps, and impact. Expect an initial response within a
few days and a reasonable window before public disclosure.

## Supported versions

Security fixes target the latest release and the Minecraft/loader versions listed in
[docs/version-matrix.md](docs/version-matrix.md). Older builds are not back-patched.
